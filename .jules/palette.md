## 2024-05-18 - Keyboard Support in Compose TextFields\n**Learning:** When using `OutlinedTextField` for inputs like terminal commands or chat messages, users expect to be able to submit using the keyboard's 'enter'/'send' action, rather than manually tapping a send button.\n**Action:** Add `KeyboardOptions(imeAction = ImeAction.Send)` and `KeyboardActions(onSend = { ... })` to `OutlinedTextField`s that represent a primary submission action.
